# Исходники UI-макетов

Код, из которого собраны картинки в `art/reference/ui-mockups/`. В игру не попадает — это эскизы стиля.

- `s01.html` … `s10.html` — экраны (смена, крупный план, назначение, ТСД, итоги, ассеты, иконки, исход, лично/поручить, титульный)
- `s11.html`, `s12.html` — окно развилки (портрет сборщика с репликой, варианты со временем и шансом жалобы) и итог развилки (иллюстрация действия сверху, чек заказа со статусом снизу). Это статичный HTML без WebGL; картинки `ui_11_fork.png` и `ui_12_fork_outcome.png` сняты Playwright в размере окна 1200×860 и 1200×1180
- `s13.html`, `s14.html` — окно назначения с пятиугольником (решение автора 21.10–07.11): сверху плашка заказа (заголовок, время, товары с адресами), по центру пятиугольник — пунктир требования заказа, заливка навыки выбранного сборщика, красное — где не хватает; кнопка «Отправить» с наградой; сборщики квадратами отдельно под окном, статус — тег внутри портрета. Процента шанса нет. `s13` — компьютер (`ui_13_assign_pentagon.png`, 1280×880), `s14` — телефон (`ui_14_assign_phone.png`, 390×844 при плотности 2). Портреты — `cut/assign_*.png` (вырезаны из скриншота игры). Статичный HTML, снят Playwright
- `world.js` — воксельный склад: стены, ворота, стеллажи, паллеты, сборщики-собаки (размеры в метрах)
- `gl.js` — простой WebGL-рендер кубов с тенями
- `ui.css`, `common.js`, `icons.js` — стиль интерфейса: скошенные углы, тёплые карточки, ромбовый паттерн на больших окнах
- `heads.html` — генерирует портреты сборщиков в `cut/vhead_*.png`

Как пересобрать: в этой папке `python3 -m http.server 8765`, затем `node render.js s01` (нужен Playwright).
